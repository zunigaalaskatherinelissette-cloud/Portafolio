A responsive, English-language portfolio built with **HTML, CSS, and JavaScript**. The visual direction follows the provided editorial reference: oversized PORTFOLIO typography, white space, beige details, lavender accents, a hanging photo badge, and colorful project cards.

## Run locally
1. Download and extract the ZIP file.
2. Keep the `assets` folder beside `index.html`.
3. Open `index.html` in a modern browser.

## Files
- `index.html` — site structure and portfolio content.
- `styles.css` — visual design and responsive layouts.
- `script.js` — mobile navigation, reveal effects, and the interactive avatar greeting.
